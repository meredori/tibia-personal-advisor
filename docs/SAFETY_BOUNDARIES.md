# Safety Boundaries

## Primary Safety Rule
Tibia Personal Advisor is an advisory tool only.

It may suggest, prioritize, estimate, and remind. It must not automate gameplay or control the game client.

## Explicitly Forbidden
- Tibia gameplay automation
- Input macros for gameplay actions
- Unattended gameplay enablement
- Reading Tibia client memory
- Scraping the Tibia game client process/UI
- Any direct control of the game client

## Explicitly Allowed
- Manual checklists and session plans
- Browser notifications and reminders
- Use of public website/API data with responsible access patterns
- User-entered data and manual overrides
- Market planning and budget planning
- Advisory recommendations and prioritization

## Enforcement Implications
- Features must remain advisory by design.
- User approval should gate higher-risk recommendation updates.
- Automation-like requests should be rejected even if technically feasible.
- Manual/static fallback paths remain required for resilience and safety.
